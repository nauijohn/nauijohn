## 🚀 What I Build

### 🖥️ [naui-linux-portfolio](https://github.com/nauijohn/naui-linux-portfolio)

An **interactive Linux desktop environment in the browser** — not your average portfolio site.

```
┌─────────────────────────────────────────────────────────┐
│  🐧 BOOT → LOGIN → DESKTOP → WINDOW MANAGER → APPS    │
└────────────────────────────────────────────────────────┘
```

| Feature | What it does |
|---------|-------------|
| **Boot Screen** | GRUB-style boot sequence |
| **Login / Lock Screen** | Auth-gated entry |
| '**Desktop Environment** | Full window management |
| '**File Manager** | Browse virtual filesystem |
| **Terminal Emulator** | In-browser shell |
| **System Tray** | System controls & status |

**Stack:** Next.js · TypeScript · Tailwind CSS · shadcn/ui · Radix UI  *
Deployed:** [naui-linux-portfolio.vercel.app](https://naui-linux-portfolio.vercel.app)
